计算机图形学：用计算机来处理和呈现现实中的物体

处理单位：像素（Pixel, Picture Element）

图形学的目标：

- Modeling
- Animation (Simulating)
- Rendering (Displaying)

!!! note "Visual Computing"

    - Computer vision: image $\rightarrow$ 3D-rep
    - Computer graphics:
        - 3D-rep $\rightarrow$ image
        - 3D-rep $\rightarrow$ 3D-rep
